# /moodboard 커맨드

## 설명
키워드 한 줄로 핀터레스트 레퍼런스를 자동 수집하고 톤·소재별로 분류해 무드보드를 완성한다.

## 사용법
```
/moodboard {키워드}
```

## 예시
```
/moodboard 미니멀 베이지 카페
/moodboard 봄 카페 인테리어
/moodboard 북유럽 홈오피스
```

## 실행 순서
이 커맨드는 아래 두 스킬을 자동으로 순서대로 실행한다:

**① moodboard 스킬** — 핀터레스트에서 이미지 30장 수집 → `./{키워드}/raw/`에 저장  
**② sort-files 스킬** — 수집된 이미지를 Vision으로 분석 → 톤·소재별 폴더로 분류

## 완료 후 결과
- 저장 위치: `./{키워드}/`
- 하위 폴더: `raw/`, `우드톤/`, `화이트톤/`, `그린포인트/` 등
- 분류 요약 리포트 출력
