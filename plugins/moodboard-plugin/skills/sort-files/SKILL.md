# 이미지 분류 스킬 (Vision 기반)

## 목표
`./raw/` 폴더의 이미지를 하나씩 분석해 톤·소재·분위기를 파악하고 카테고리 폴더로 이동시킨다.

## 분류 기준

| 카테고리 | 설명 | 예시 |
|---------|------|------|
| 우드톤 | 나무·원목 소재 중심 | 원목 테이블, 대나무 소품 |
| 화이트톤 | 흰색·밝은 회색 위주 | 화이트 인테리어, 미니멀 |
| 그린포인트 | 식물·자연 요소 포함 | 화분, 잎사귀, 자연 채광 |
| 빈티지 | 레트로·앤틱 느낌 | 낡은 가구, 빈티지 소품 |
| 다크톤 | 어두운 색감 위주 | 블랙, 진한 네이비, 차콜 |
| 컬러포인트 | 선명한 포인트 색상 | 노랑, 빨강, 파랑 강조색 |
| 기타 | 위 카테고리에 해당 없음 | |

## 실행 단계

### 1. 이미지 목록 확인
`./raw/` 폴더의 이미지 파일 목록 수집

### 2. Vision 분석 루프
각 이미지에 대해:
1. 이미지 읽기
2. 주요 색조, 소재, 분위기 파악
3. 위 분류 기준에 맞는 카테고리 결정
4. 해당 카테고리 폴더로 이동 (폴더 없으면 생성)

### 3. 결과 요약
분류 완료 후:
```
✅ 분류 완료
- 우드톤: N장
- 화이트톤: N장
- 그린포인트: N장
- 빈티지: N장
- 다크톤: N장
- 컬러포인트: N장
- 기타: N장
```

## 주의사항
- 원본 파일은 카테고리 폴더로 이동(복사 아님)
- 분류 불명확한 이미지는 "기타" 폴더로
- 이미 분류된 파일(raw/ 이외 위치)은 건드리지 않음
